# New Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a player ring, a click-the-corners zone, a Solid/Dashed switch for the line tools, and a callout label, and fix the text-font and arrowhead-anchor bugs.

**Architecture:** New tools are small modules behind one thin dispatch in `DrawingCanvas.tsx`; the ten existing tools stay in place. Ring and zone are two-child "surface shape" groups (fill + outline) so contrast styles hit only the edge. Dashed is a per-annotation flag whose dash pattern is derived, with a reveal that shows dashes progressively. Geometry and construction are pure, unit-tested functions.

**Tech Stack:** Electron, React 18, TypeScript, Zustand, Fabric.js 5, Vitest (jsdom).

**Spec:** `docs/superpowers/specs/2026-11-25-new-tools-design.md`. Read it before any task.

## Global Constraints

- Work on branch `new-tools` (create from `main`). Conventional commits. Do not push. Never touch `git stash`.
- The ten existing tools' behaviour and code paths do not change, apart from: the two bug fixes, the `dashed` flag on line/arrow/arc-arrow/pen, and the colour picker keeping a translucent fill's alpha.
- Projects saved by 1.8.0 (and version `'1.3'` files with speed regions) load and export exactly as before.
- Hidden features stay hidden (tracker/YOLO, audience view, laser pointer). No new dependencies. No IPC changes.
- Exact values: `RING_FLATTEN = 2.5`; `RING_FILL_ALPHA = 0.18`; ring minimum `rx` 12 px, click-without-drag `rx` 40; `ZONE_FILL_ALPHA = 0.25`; zone closes within 10 px of the first corner; at least 3 corners; dash pattern `[3w, 2w]` for stroke width `w`; callout dot radius `max(3, 1.5w)`; callout click-without-drag (under 8 px) label offset 80 px right and 80 px up; reveal threshold 0.85; defaults — ring `drawIn 0.4`, zone `fadeIn 0.2` `fadeOut 0.15` `drawIn 0`, callout `drawIn 0.3` `fadeOut 0.15`; keys `G` ring, `Z` zone, `Shift+T` callout, `D` toggle dash; project file version `'1.4'`.
- A two-child group is not automatically an arrow: reveal, restyle and recolour branch on `toolType` first.
- **Testing budget (owner's instruction):** run only the test files for the code you touch (`npx vitest run <files> --no-file-parallelism`), plus `npm run typecheck` and `npm run lint` (0 errors) before each commit. Do NOT run the full suite and do NOT run the app; a major full test of this release and the previous one happens once, after all tasks.
- Don't add comments or types to code you didn't change.

## Review Focus

1. **Undo, redo, save/load and export clone of each new shape**: a ring, a zone, a dashed arrow and a callout come back as the same thing (type, geometry, fill alpha, dash, plate, callout uncached), never as a rectangle or a solid line. (Tasks 1-5)
2. **A zone half-built when something else happens**: tool switch, playback starting, a timeline click, a colour change, Delete/Backspace/Escape/Space pressed. No orphan preview objects, no annotation created, no other shortcut fired by mistake. (Task 3)
3. **A dashed line mid-reveal and at the ends of it**: fraction 0 shows nothing, fraction 1 shows the plain pattern, `stripReveal` restores it, the arrowhead stays solid, and a solid line's reveal is unchanged. (Task 4)
4. **Callout text entry edge cases**: empty text, Escape, the commit click not starting another callout, a label dragged to each side of the target, a very long label. (Task 5)
5. **Old data**: a 1.8.0 project with arrows (no saved origins), round-capped lines (no saved caps) and no `dashed` flags loads and looks as it did; an unknown Fabric type is skipped with one toast, not turned into a rectangle. (Task 1)

Behaviour:
- `ToolType` gains `'ring' | 'zone' | 'callout'`. - `DrawingCanvas.tsx`: a `NEW_TOOLS: Partial<Record<ToolType, CanvasTool>>` map. At the top of the mouse down/move/up handlers, if the current tool is in the map: build the `ToolContext` from current store values (read at call time, not from a stale closure), call the handler, return. Gesture state lives in the tool module or a ref, so it survives the effect re-subscribing on colour/width/style changes. On tool change, call the previous tool's `cancel`. Frame capture (`captureDrawFrame`) runs on down as for other drawing tools.
- Ring tool: down sets the centre and adds a preview surface shape; move updates radii via `ringRadii`; up commits (`'ring'`), with a click (pointer moved under 4 px) giving `rx = RING_CLICK_RX`. Both ellipses use `originX/originY: 'center'`.

- `reveal.ts`: `revealKind('ring') === 'ring'`, `'zone' → 'none'`, `'callout' → 'callout'` (implemented in Task 5; until then it behaves as 'none'). `applyReveal` branches on kind before looking at group shape. - Colour picker (`AnnotationTimeline.tsx` `handleColorChange`): when a fill is a translucent `rgba(...)`, set it to `recolorKeepingAlpha(fill, color)` instead of the opaque colour. Opaque fills behave as before.
- Toolbar: a "Field" group after the shapes with the Ring button (`G`).

export const ZONE_FILL_ALPHA = 0.25, ZONE_CLOSE_PX = 10, ZONE_MIN_CORNERS = 3, ZONE_DUPLICATE_PX = 2
export function zonePathData(points: ToolPoint[]): string                       // 'M 10 10 L 50 10 L 50 40 Z'
export type ZoneClick = { type: 'add'; point: ToolPoint } | { type: 'finish' } | { type: 'ignore' }
/** A click near the first corner (with ≥ 3 corners) finishes; a click within ZONE_DUPLICATE_PX of the last corner is ignored (double-click's second click). */
export function zoneClick(points: ToolPoint[], point: ToolPoint): ZoneClick
export type ZoneKey = 'finish' | 'cancel' | 'undo-corner' | 'swallow' | 'pass'

Key handling: a `window` keydown listener in the **capture phase**, installed by the canvas, calls the current tool's `onKey`; when it returns true the event gets `preventDefault()` and `stopImmediatePropagation()`. Never intercept when the event target is an input, textarea, select or contentEditable. While `isBusy()`: if the video starts playing or seeks (subscribe to the store's `isPlaying` / listen for `seeking` on the element), call `cancel`. Tool switch calls `cancel` (Task 2's dispatch). // lineDash.ts
export const DASH_TOOL_TYPES: ReadonlySet<string>                 // 'pen', 'path', 'line', 'arrow', 'arc-arrow'
export function dashPattern(strokeWidth: number): [number, number]      // [3w, 2w]
/** The object that carries the stroke: the shaft of an arrow group, else the object itself. */
export function strokeTarget(object: fabric.Object, toolType: string): fabric.Object
/** Sets or clears strokeDashArray, strokeLineCap ('butt' when dashed, the tool's usual cap when solid) and strokeUniform on the stroke target. */
export function applyDash(object: fabric.Object, toolType: string, dashed: boolean): void
/** Dash array showing `pattern` along the first fraction×length and nothing after. Even length; last entry (a gap) ≥ length. */
export function revealDashArray(pattern: [number, number], length: number, fraction: number): number[]
// toolStore.ts
lineDash: 'solid' | 'dashed'; setLineDash(v): void; toggleLineDash(): void
// reveal.ts
export function applyReveal(object: fabric.Object, toolType: string, fraction: number, opts?: { dashed?: boolean }): void
```

Behaviour: the control sits beside the style control ("Solid | Dashed"), `D` toggles. New drawings from `DASH_TOOL_TYPES` get `dashed: lineDash === 'dashed'` and `applyDash`. With such drawings selected, the control sets `dashed` and re-applies as one undo step (the style control's pattern; `saveState()` once). The pattern is re-applied when the stroke width of a dashed drawing changes, on project load, and after undo/redo restore if the canvas JSON does not carry it faithfully. Reveal: when `opts.dashed`, `revealStroke` uses `revealDashArray(dashPattern(strokeWidth), length, fraction)` with `strokeDashOffset 0` instead of `[length, length]`; the saved original (the plain pattern) is restored at fraction 1 and by `stripReveal`. `useLiveReveal.ts` and `clipRenderer.ts` pass `{ dashed: annotation.dashed }`.
